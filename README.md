# 盛唐夜市 · 升级计算器

「时光大爆炸」盛唐夜市玩法的升级决策辅助工具。单 HTML 文件，浏览器直接打开即用。

**在线使用 →** https://mujian0086.github.io/tang-night-market-calc/

## 功能

- **升级性价比排行**：按当前阶段权重（滚雪球/梭哈/铺楼/成熟）计算每项升级的性价比得分
- **均衡加权**：低收益建筑自动获得优先提升
- **宣传册模拟**：4 种使用策略（单张/小批/大批/梭哈）对比模拟后收益
- **冲榜预估**：客流柱状图 + N 小时客流预测 + 15 天周期倒计时
- **解锁距离加权**：距离下一次客流/培训解锁 ≤3/6/10 级时自动提升该建筑升级优先级
- **开新楼分析**：综合均值稀释、尾楼比例、宣传册数量判断是否适合扩张
- **一键执行升级**：排行中点击即自动更新对应建筑数据
- **数据持久化**：localStorage 自动保存，支持导出/导入 JSON

## 利润公式

```
利润 = 单价 × 客流 ÷ 10000 × (1 + 店长% + 部件% + 培训%) × (1 + 终利%)
```

培训%由利润反推：`培训% = 利润 ÷ (基础利润 × 终利倍率) - 1 - 店长% - 部件%`

## 使用

1. 下载 `index.html` 或直接访问 GitHub Pages 链接
2. 从游戏中逐栋录入建筑数据（单价、客流、利润、升级增量和费用）
3. 排行自动计算，点「执行」一键升级

## 阶段系统

| 阶段 | 条件 | 策略 |
|------|------|------|
| 滚雪球 | 2 栋 | 两楼同步拉高，宣传册逐本用 |
| 梭哈 | 2 栋 + 50-80 宣传册 + 尾楼≥88% | 一次性用完宣传册 |
| 铺楼 | 3-7 栋 | 持续开楼，后排更强但中间别断层 |
| 成熟 | 8 栋全开 | 常规 ROI，补客流与低成本项 |
